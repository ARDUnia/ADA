# Security policy

## Supported version

Security fixes currently target the latest code on the `main` branch.

## Reporting a vulnerability

Please do not publish credentials or an exploitable vulnerability in a public issue. Contact the project owner through [ardunia.ir/contact](https://ardunia.ir/contact) with:

- affected version or commit
- hardware and network context
- reproduction steps
- expected impact
- a suggested fix, if available

## Deployment notes

- Change the default `ADA-Config` password before distributing a device.
- The configuration portal is intended for local setup, not exposure to the public internet.
- Do not place private credentials in source files.
- Review Wi-Fi and web-server behavior before using ADA on an untrusted network.
